# 🦠 COVID‑19 Data Analytics Dashboard

## 📌 Project Description
This project delivers an interactive **COVID‑19 Dashboard** built to track, analyze, and visualize the global impact of the pandemic. It provides clear insights into confirmed cases, deaths, recoveries, and growth trends across countries and regions, enabling stakeholders to understand the spread and make informed decisions.

---

## 🛠 Tech Stack
- **Power BI** – Dashboard design and visualization  
- **SQL (PostgreSQL/MySQL)** – Data extraction and transformation  
- **Excel** – Data cleaning and preprocessing  
- **Python (basic scripts)** – Data manipulation and automation  

---

## 📂 Data Source
- **COVID‑19 dataset** containing daily records of confirmed cases, deaths, recoveries, and regional breakdowns.  
- Data was cleaned and structured using **Excel and SQL** before being imported into Power BI for visualization.  
- Publicly available datasets (e.g., WHO, Johns Hopkins University) were used as the foundation.

---

## ✨ Features
- **Global KPIs**: Total confirmed cases, deaths, recoveries, and death rate  
- **Geographical Insights**: World map visualization with bubble sizes and color intensity showing severity  
- **Top 10 Countries**: Bar charts for confirmed cases and death rates  
- **Regional Analysis**: Donut chart breaking down WHO regions  
- **Trend Analysis**: Weekly % increase line chart highlighting fast‑growing countries  
- **Interactive Filters**: Explore by region, country, or growth rate  

---

## 💡 Example Business Problems Addressed
- Which countries are experiencing the **fastest growth** in cases?  
- How do **death rates** vary across regions?  
- Which regions require **urgent healthcare resource allocation**?  
- What are the **long‑term trends** in recovery rates?  

---

## 📈 Key Insights
- Certain regions show **rapid growth trends**, requiring immediate intervention.  
- **Death rates** vary significantly, highlighting disparities in healthcare infrastructure.  
- **Recovery data gaps** emphasize the importance of consistent reporting.  
- Interactive filters allow **executives and policymakers** to drill down into specific regions for targeted decision‑making.
